# US → KR Market Radar

실제 가격을 읽는 개인용 관찰 대시보드. 국내 10종목, 미국 11종목, 지수 4개. Yahoo Finance 비공식 조회이며 지연/중단될 수 있습니다. 투자 추천·실시간 호가 서비스가 아닙니다.

## 실행과 배포
Node 22 이상. npm run dev / npm test / npm run build. Vercel Other 프리셋, main 브랜치 Git 연결. api/market 및 api/disclosures가 서버에서 실행됩니다. DART_API_KEY를 Vercel 서버 환경변수로 설정합니다. 공개 코드에 키를 넣지 마세요.

## 데이터와 예약 작업
페이지는 처음 열 때 서버 시세를 조회하고, 열린 상태에서는 12시간 주기로 자동 갱신합니다. 필요하면 '새로고침' 버튼으로 즉시 다시 조회할 수 있습니다. 실패하면 GitHub의 최근 성공 스냅샷을 가져오며 기준시각을 표시합니다. 96시간 이상 시세는 확인 불가로 표시합니다. 주말·휴장일에도 최근 가격은 표시될 수 있으므로 거래시각을 확인해야 합니다.

GitHub Actions refresh.yml은 UTC 23:40 일–목(한국장 08:40), UTC 20:35/21:35 월–금(미국장 마감 후), UTC 12:25/13:25 월–금(미국장 개장 전)에 실행합니다. 서머타임 양쪽 시간대를 수집하고 거래소 휴장일에도 마지막 가격을 저장합니다. GitHub 예약은 지연될 수 있으며 60일 활동이 없으면 공개 저장소 예약이 비활성화될 수 있습니다. 수집 성공률 70% 미만이면 실패 처리하고 이전 파일을 보존합니다. Actions 로그에서 상태를 확인하세요.

DART는 최근 7일 공시 중 최신 100건을 조회합니다. 전체 기업/기간 전수조회가 아니며, 상세의 관련 공시가 비어도 공시 부재를 뜻하지 않습니다. 키 없이 가격 기능은 사용 가능합니다.

## 분석 범위
등락률은 조회 범위의 시작 가격이 아닌 직전 거래일 종가 대비 계산합니다. 가격이 직전 종가 대비 -5% 이하 또는 +7% 이상이면 AVOID 가격 경보, 나머지는 WATCH입니다. 직전 20거래일 평균과 현재 가격을 비교합니다. 장중 거래량은 미완성입니다.

미국→한국 연결은 산업 테마 가설이며 검증된 고객/공급계약이 아닙니다. 서로 다른 시장의 최근 거래시각을 함께 표시하며 인과관계 점수를 생성하지 않습니다.

보유수량은 현재 브라우저 localStorage에만 저장하며 지원 종목에 대해 통화별 평가금액과 가격 경보를 제공합니다. 계좌 연결·동기화·자동매매 없음.

BUY/SELL 종합 점수, 프리마켓·옵션, 공시 본문 해석, lead-lag, 검증된 공급망 DB, 백테스트는 미구현입니다. 원래 100점 계산 모듈은 보존되어 있으나 운영 신호에 사용하지 않습니다.

## KIS 조회 연결과 관찰 점수 v1
Vercel Production의 Secret 환경변수 KIS_APP_KEY, KIS_APP_SECRET을 설정하고 재배포합니다. 실전 endpoint를 사용하지만 구현된 요청은 토큰 발급, KRX 일봉, 투자자 조회뿐이며 계좌번호·주문 기능을 사용하지 않습니다. 키·토큰은 응답과 로그에 출력하지 않습니다. KIS는 완료 일봉만 사용하고 당일은 KST 16시 이후 포함합니다. 수급은 동일 기준일만 반영합니다. 호출 실패 시 Yahoo 보조 시세와 잠정 점수를 사용합니다. GitHub 스냅샷에는 KIS 자격증명을 설정하지 않습니다.

토큰은 함수 인스턴스 메모리에 만료 5분 전까지 보관합니다. 여러 cold start 사이에서는 공유되지 않으므로 발급 제한이 생기면 해당 요청은 보조 시세로 전환됩니다. 자동 서버 시세 조회를 12시간 간격으로 줄여, 페이지를 계속 열어둔 경우 KIS 토큰 발급을 하루 2회 수준으로 제한하도록 했습니다. 페이지를 새로 열거나 수동 새로고침을 누르면 추가 조회가 발생할 수 있습니다.

관찰 점수는 추세25, 모멘텀20, 상승 거래량15, 급변 억제20, 국내 수급20의 규칙 기반 합계입니다. 미국은 수급 없이 80점 기준. 확보된 항목만 100점으로 환산하고 데이터 충족률·잠정 여부를 표시합니다. 충족률60% 미만 또는 96시간 이상 지난 시세는 계산을 보류합니다. 장중 미완성 거래량은 제외합니다. 항목별 식은 public/scoring.js와 상세 화면에 공개합니다. 높은 점수는 상승확률이 아닙니다. 공시 내용과 미국→한국 인과관계는 미반영이고 백테스트 전입니다.
