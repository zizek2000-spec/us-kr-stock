# US → KR Market Radar

한국어 시장 관찰 대시보드의 첫 데모 버전입니다. 실제 시세/뉴스 수집, 공급망 검증, 백테스트 및 투자 추천 서비스는 아직 구현되지 않았습니다.

## 실행

Node.js 22 이상에서 `npm run dev` 후 http://localhost:4173 접속. `npm test`로 점수 경계값 검증, `npm run build`로 dist 생성. 외부 패키지는 없습니다.

## 기능

- 한국/미국 시장 탭, 종목·테마 검색, BUY/WATCH/AVOID 필터
- 평가 점수 구성, 근거와 무효화 조건 상세 보기
- 보유종목 추가/삭제 (현재 브라우저 localStorage에만 저장; 클라우드 동기화 없음)
- 테마 연결 예시 및 데이터 연결 현황
- 모바일 화면, 키보드 조작, 명시적 DEMO 표시

## GitHub → Vercel 자동 배포

Vercel에서 이 GitHub 저장소를 Import하고 Framework Preset을 Other로 선택합니다. vercel.json의 buildCommand와 outputDirectory를 사용합니다. 연결된 production branch의 push마다 Vercel이 클라우드에서 빌드/배포합니다. 사용자 PC가 켜져 있을 필요가 없습니다. Actions는 검증을 수행하며 Vercel Git integration이 배포합니다. 검증 완료를 배포 선행조건으로 설정한 것은 아닙니다.

## 실제 자동 분석으로 확장할 때 필요한 작업

1. 서버 전용 KIS/Massive/DART 키 및 SEC 식별자 설정. 키를 공개 저장소에 커밋하지 않습니다.
2. 거래일·휴장일·미국 DST를 반영하는 수집 일정과 공급자별 API 어댑터 구현.
3. 클라우드 DB에 기준시각, 원문 URL, 수집상태, 유효기간, 원시 지표 저장.
4. 공급 관계 검증 자료 및 60거래일 선행 상관 계산, 진입 갭/유동성 필터 구현.
5. 결측·오래된 데이터는 BUY 평가에서 제외하고, 이전 성공 결과는 오래됨으로 표시.
6. 실제 3/6/12개월 데이터로 거래비용·슬리피지·생존편향·미래정보 사용을 통제한 백테스트.
7. 예약 분석 실행 및 보유종목 위험 계산, 로그인과 서버 저장 구현.

Vercel Hobby Cron은 작업별 하루 1회 및 시간 단위 정밀도 제한이 있어 08:40 정시 분석에는 적합하지 않습니다. GitHub Actions 예약도 지연될 수 있습니다. 정밀한 장전 분석에는 적절한 클라우드 스케줄러 또는 Pro Cron을 검토해야 합니다. 현재 이 저장소에는 시장 데이터 수집 예약 작업이 없습니다.

85점 이상은 강한 BUY 후보, 75–84 BUY, 65–74 WATCH라는 원안을 기준으로 합니다. 예시 표의 76 WATCH와 충돌하므로 명시된 점수 구간을 우선했습니다. 위험점수는 50 이상 REDUCE, 70 초과 EXIT입니다. 최종 실전 신호에는 결측 처리와 신호 만료가 추가되어야 합니다.
